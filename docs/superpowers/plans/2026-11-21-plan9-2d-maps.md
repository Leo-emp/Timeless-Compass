# 2D Maps in the Film Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Epic-History-style parchment maps drawn in our 2D style inside the Remotion film engine (spec 6.16, r14 look, r35 build): world/region, route, territory-change and battle maps, with a low tilted camera, a spotlight on the place being talked about, and small cast-style figures, ships and banners on the map. Shorts get vertical maps.

**Architecture:** Python keeps the geography (Natural Earth coastlines/rivers via the existing `tc/maps/geo.py`, borders per era from `jobs/<id>/map/`) and exports one simplified SVG path set per map (`film/src/jobs/<slug>/maps/<map>.json`, projected + simplified, no fonts). A TypeScript map kit draws parchment (paper tone, stains, coast hatching, sea lines), labels as vector text (kit `text.ts`), routes that draw on the word, territory fills that change on the word, unit blocks that slide/turn/charge, and a perspective "tilted table" camera. The old Blender texture painter (`tc map paint`) is retired.

**Tech Stack:** Python (shapely-free: existing raster/geo helpers + Douglas–Peucker), TypeScript kit, Remotion.

**Spec:** `docs/superpowers/specs/2026-11-21-2d-autonomous-agent-design.md` (6.16)

## Global Constraints

- Natural Earth (public domain) only; no map tiles, no AI images (r15).
- Text is vector paths (never load fonts at render time); labels never overflow their box (still check).
- Era-correct borders and names from the research (r4); disputed borders drawn dashed.
- Same look across a video; fresh composition per video (r17).

## Review Focus

1. **A projection/aspect bug** that squashes coastlines on 9:16 Shorts → `test_projection_keeps_aspect_vertical`.
2. **Huge path data** (unsimplified coastlines) that stalls renders → `test_map_json_under_budget`.
3. **Labels overlapping** each other or coastlines → `test_labels_do_not_overlap`.
4. **A route that does not land on its word** → `test_route_progress_follows_beat`.
5. **Missing era borders file** → clear error naming the file, not a blank map → `test_missing_borders_named`.
